# Codex Web v2.0.0

提供可通过 npm 全局安装的 Codex 浏览器客户端。安装包包含已构建网页，目标机器无需克隆仓库或构建前端。

## 安装

目标环境：Linux、systemd、Node.js 24+、npm、已安装并登录的 Codex CLI，以及 `/usr/bin/zsh`。

```bash
npm install -g https://github.com/hjd-hitsz/codex-web/releases/download/v2.0.0/codex-web-2.0.0.tgz
codex-web service install
loginctl enable-linger "$USER"
codex-web service status
```

`loginctl enable-linger` 可能需要管理员授权。服务启动后访问 `http://电脑IP:8766`；本机可使用 `http://127.0.0.1:8766`。

## 功能

- 通过浏览器使用本机 Codex 的聊天、文件、Git 和交互式终端。
- `codex-web` 命令提供前台启动、配置初始化及后台服务管理。
- systemd 用户服务支持开机自启动，并保留已有 Codex 后端配置。
- 用户配置保存在 `~/.config/codex-web/.env`，独立于 npm 安装目录。
- 对话按实际完成时间排序，工作过程默认折叠，最终回答独立显示。

## 附件与验证

- `codex-web-2.0.0.tgz`：用于 `npm install -g` 的预构建安装包。
- `codex-web-2.0.0.tgz.sha256`：安装包 SHA-256 校验文件。将两个文件下载到同一目录后执行 `sha256sum -c codex-web-2.0.0.tgz.sha256`。

发布流程执行 `npm run check`，包含格式检查、单元测试、组件测试、生产构建和隔离的 npm 全局安装测试。GitHub 自动生成的 Source code 附件用于源码开发，直接安装请使用上述 `.tgz` 附件。

已有安装可执行上面的 npm 安装命令更新，再执行 `codex-web service install` 和 `codex-web service restart-when-idle` 切换到新版本。
