# Codex Web v2.3.1

- 新增 `/init` 项目指令生成与 `/goal` 任务目标管理；已有 `AGENTS.md` 可直接打开，任务目标支持编辑、暂停、恢复、清除及可选 token 预算（[1e5fb6f](https://github.com/hjd-hitsz/codex-web/commit/1e5fb6f1716f6d7da869f22266caf6c5d19bb63a)）。
- `/stop` 可查看并清理当前对话的后台终端；命令菜单、发送按钮和 Ctrl+Enter 统一处理命令参数，发送失败时保留输入与附件（[1e5fb6f](https://github.com/hjd-hitsz/codex-web/commit/1e5fb6f1716f6d7da869f22266caf6c5d19bb63a)）。
- 回复批注支持连续添加多条，在原文旁通过圆角浮层编辑，并随正文和附件一次发送；刷新、切换对话及发送失败时保留全部批注草稿（[644b302](https://github.com/hjd-hitsz/codex-web/commit/644b3020ecf3d248c10512c880fa188acae57a85)）。
- 整理上下文时持续显示状态与耗时，完成、失败或中断后恢复发送；修复提交后立即刷新导致提示消失，以及后台重连后整理状态持续卡住的问题（[1e5fb6f](https://github.com/hjd-hitsz/codex-web/commit/1e5fb6f1716f6d7da869f22266caf6c5d19bb63a)、[c71c8b9](https://github.com/hjd-hitsz/codex-web/commit/c71c8b904060bba3eb354fe0174b0ee3867b7f12)、[573fb21](https://github.com/hjd-hitsz/codex-web/commit/573fb2133d23cc391073ca0486c6dd3ea3082a81)）。
- 任务结束后，未作答的问题自动收入工作过程并显示“提问已结束”；展开记录可继续补充回答，保留尚未提交的选项和文字（[6eac6b3](https://github.com/hjd-hitsz/codex-web/commit/6eac6b3e5923a63d520cfdc12a49d688d49858da)）。
- 深浅主题采用更清晰的中性灰阶与中文字体，适度放大正文、输入框和侧栏文字，统一控件圆角与层次，同时保留全宽聊天布局（[12a7e19](https://github.com/hjd-hitsz/codex-web/commit/12a7e1966ff3d775e42168e5e1b4fd6c242ecca7)）。
