# Codex Web v2.1.2

本版汇总自 v2.1.1 以来的输入框、消息展示、思考摘要和对话管理改进，修复本地图片与 Mermaid 图表显示，并完善同版本发布重试。安装命令、用户配置和聊天数据沿用现有方式。

## 功能与修复

### 输入与对话管理

- 输入框与模型弹窗通过闪电图标切换标准与 Fast，绿色实心表示加速，灰色描边表示标准；首次读取 Codex 配置，恢复对话和跨页面通知同步实际速度（[f33929f](https://github.com/hjd-hitsz/codex-web/commit/f33929ff7f9b00628e6865145efd66a545c63fa1)、[f8fc681](https://github.com/hjd-hitsz/codex-web/commit/f8fc681888ca41ed4a01087ac568a51c5c225d11)）。
- 新建与发送显式携带服务档位，切换标准时清除 Fast；重连和失败重试保留选择，运行中补充消息沿用当前轮次速度，切换模型时仅保留其支持的档位（[f33929f](https://github.com/hjd-hitsz/codex-web/commit/f33929ff7f9b00628e6865145efd66a545c63fa1)）。
- 思考强度改为按模型支持档位排列的拖拽滑块，输入框点击后展开，模型弹窗直接显示，支持方向键调整；工具栏保留附件、模型、思考强度、速度与计划模式，技能通过侧栏或快捷命令进入，窄屏保留常用入口（[f8fc681](https://github.com/hjd-hitsz/codex-web/commit/f8fc681888ca41ed4a01087ac568a51c5c225d11)）。
- 输入框下方常显最近一轮 tokens、上下文窗口容量和使用百分比，窄屏自动换行；尚无用量数据时显示发送快捷键（[ae7a0d7](https://github.com/hjd-hitsz/codex-web/commit/ae7a0d7b522a914f5a4adf9438220ec52b9280b1)）。
- 修复首次发送成功后，新建对话仍重复填入已发送消息的问题；创建成功后转存草稿，发送成功清理对应内容，保留未发送、发送失败及等待结果期间继续编辑的草稿（[bc204f6](https://github.com/hjd-hitsz/codex-web/commit/bc204f65b59961b810d6fc4f71b32805098977d2)）。
- 对话行右侧常显一键归档按钮，归档列表提供直接恢复按钮；标题、时间和按钮分别占位，桌面与触屏均可操作，并保留三点菜单（[6e6b895](https://github.com/hjd-hitsz/codex-web/commit/6e6b8955bcc3b1725e27bce11e04ce3d9738ba31)）。
- 修复网页未分类对话在列表缺少来源标记时显示为独立文件夹的问题；结合网页创建者与专用自动目录恢复分类，明确项目归属继续优先（[a174097](https://github.com/hjd-hitsz/codex-web/commit/a174097bfb2ff03fb599d1db2009bc0ca772196c)）。

### 消息与工作过程

- Markdown 的 `mermaid` 代码块自动绘制图表，支持深浅主题、源码切换与复制；流式内容尚未完整或解析失败时保留源码，按需加载的图表资源随安装包交付（[4b0fc69](https://github.com/hjd-hitsz/codex-web/commit/4b0fc69c92281ca32f65d4fe77bc173fee344681)）。
- 本地图片和历史图片附件通过现有文件读取通道加载，支持绝对路径、所属对话目录下的相对路径、`file:` 与 `sandbox:` 引用，并支持失败重试和断线恢复（[b931204](https://github.com/hjd-hitsz/codex-web/commit/b931204a4be39e6e16624ddc190000ac717814aa)）。
- 消息图片使用最大 320 × 240 像素的等比缩略图，点击后可切换适应窗口与原始尺寸；关闭按钮、Esc 和空白区域均可关闭大图，关闭后焦点返回缩略图（[b931204](https://github.com/hjd-hitsz/codex-web/commit/b931204a4be39e6e16624ddc190000ac717814aa)）。
- 每轮进度、思考摘要和工具记录汇总为一个默认折叠的工作过程，中途引导独立显示；完整过程位于该轮最后一条用户消息或提问下方、最终回答上方，后移时保留展开状态，流式生成和历史恢复保持一致（[def4a52](https://github.com/hjd-hitsz/codex-web/commit/def4a52785f9b7469c14c55442d3ed06aaa8c386)）。
- 任务生成且工作过程折叠时，在区域外持续显示最新有效提示并随流式内容更新；多段摘要只预览最后一段，轮次完成后收起提示，展开后显示完整过程（[3486644](https://github.com/hjd-hitsz/codex-web/commit/34866447ab3c6aa6c5c04d72409dcc200213f7be)）。

### 思考摘要与工具描述

- 命令记录与实时提示使用本地中文操作描述，涵盖技能阅读、文件读取、搜索、Git 检查、项目测试与构建及常见系统查询；技能标题只显示名称和必要行范围，组合命令保留顺序、条件与管道关系，展开可查看原始命令、输出、退出码和工作目录（[ac5ca83](https://github.com/hjd-hitsz/codex-web/commit/ac5ca83df31e0c63f13f28b68883cb6b598601e5)）。
- 思考摘要改为浏览器直连 TranSmart 普通机器翻译，独立于 Codex 对话与模型，合并请求并缓存译文，请求前保护代码、路径和链接；接口失败时保留原文并支持重试（[dbf5088](https://github.com/hjd-hitsz/codex-web/commit/dbf50885c88c9102e7a0c1a4776242ff5df64ae0)）。
- 摘要显示时同时翻译标题和正文，正文折叠期间继续跟进流式更新，展开以及切换实时预览与历史过程时复用译文（[b299030](https://github.com/hjd-hitsz/codex-web/commit/b2990306c056501d0daa5212e997eefba6e31353)）。

### 发布可靠性

- 发布失败后继续用户确定的同一版本；明确版本号的重复准备保留已审阅内容，尚未创建标签的批次阻止继续递增。附件先完整上传到同版本草稿再正式发布，部分上传中断后复用草稿，发布成功后响应中断的重试保留正式附件，并补充相应回归测试与维护约定（[d530757](https://github.com/hjd-hitsz/codex-web/commit/d530757d4d14919468580010e5f10b39cc664552)）。

## 环境与安装

目标环境：Linux、Node.js 24+、npm、已安装并登录的 Codex CLI，以及 `/usr/bin/zsh`；后台服务使用 systemd。本项目已在 Codex CLI `0.162.1` 上验证。

```bash
npm install -g https://github.com/hjd-hitsz/codex-web/releases/download/v2.1.2/codex-web-2.1.2.tgz
codex-web service install
loginctl enable-linger "$USER"
codex-web service status
```

`loginctl enable-linger` 用于开机启动用户服务及退出登录后继续运行，可能需要管理员授权。启动后访问 `http://电脑IP:8766`，本机可访问 `http://127.0.0.1:8766`。

## 从 v2.1.1 升级

安装新版、更新服务中的安装路径，并等待网页任务与终端空闲后重启网页服务：

```bash
npm install -g https://github.com/hjd-hitsz/codex-web/releases/download/v2.1.2/codex-web-2.1.2.tgz
codex-web service install
codex-web service restart-when-idle
```

用户配置保存在独立配置目录。刷新网页后，在“设置 → 关于”分别核对网页和桥接均为 `2.1.2`，也可查看磁盘安装包与运行进程的来源：

```bash
codex-web --version
codex-web version --json
curl http://127.0.0.1:8766/healthz
```

从 v2.0.0 升级时，同时按[对话占用与后端回收说明](https://github.com/hjd-hitsz/codex-web/blob/v2.1.2/docs/deployment.md#对话占用与后端回收)核对已有 Codex 后端的 `thread_unload_delay_secs=0` 启动参数。

思考摘要翻译需要浏览器访问 `transmart.qq.com`，待译摘要会发送至该服务；代码、路径与链接在请求前替换为占位符。
