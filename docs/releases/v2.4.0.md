# Codex Web v2.4.0

- 文件面板支持图片、音视频和 PDF 预览，Office 文档、压缩包等可下载原文件；修复部分文件链接打开后仅提示使用本机应用的问题，预览失败时可重试或下载（[351ee89](https://github.com/hjd-hitsz/codex-web/commit/351ee8927efee988dd980e06bac27cd7d211756c)）。
- 项目侧栏支持拖动右侧边缘调整宽度，按窗口空间和字体尺寸自适应；刷新和重新展开后保留调节比例，双击边缘恢复自动宽度。界面字号与间距随基础字号变化，放大字体时文字条目随内容增高，代码编辑器和终端同步调整字号与行高（[610c382](https://github.com/hjd-hitsz/codex-web/commit/610c382424f2ba360362e6a983f9237f5df78e71)）。
- 工作过程中的图片直接显示可放大的缩略图；网页搜索、打开页面、页内查找及其他工具结果展示操作、文字、链接和内容，并保留错误说明（[2905c4b](https://github.com/hjd-hitsz/codex-web/commit/2905c4bff3047a961d1e1a1ade60151e7e3b945b)）。
- 修复部分客户端对话无法查看历史的问题，自动读取完整消息；对话由另一端占用时仍可查看已保存的消息（[79f56a8](https://github.com/hjd-hitsz/codex-web/commit/79f56a86194b87e488373e83495d4ddbcf4633a3)）。
- 修复思考摘要折叠后重新展开时重复翻译的问题；同一标签页内切换对话和刷新页面继续复用译文，关闭标签页或浏览器后清空会话缓存（[37ad429](https://github.com/hjd-hitsz/codex-web/commit/37ad4291d711261f06f35857e38ddbd438d36e0f)）。
- 浏览器标签页、侧栏和欢迎页统一使用 Codex Web 专属图标，并修复部分手机浏览器仍显示默认地球图标的问题（[d6e3872](https://github.com/hjd-hitsz/codex-web/commit/d6e3872bdb29d30641863bbed3cdffde7e77caec)、[21ba82c](https://github.com/hjd-hitsz/codex-web/commit/21ba82c3804eea77f00bcf3ffb25d6fe9fc0c16a)）。
