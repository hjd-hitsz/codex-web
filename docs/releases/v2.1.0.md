# Codex Web v2.1.0

- 可以从“未分类”直接新建聊天，每个聊天拥有独立文件夹，已有项目中的聊天保持原归属（[8cfd1f6](https://github.com/hjd-hitsz/codex-web/commit/8cfd1f66b475f9138614b8195776cde7cc35acd8)）。
- 任务中的提问以独立卡片显示，支持选择选项或填写回答，回复问题时保留输入框草稿和附件（[1010608](https://github.com/hjd-hitsz/codex-web/commit/1010608e66bb6fa2bf733c52c60b8317f9f62bf7)）。
- 在“设置 → 关于”查看网页和服务版本，方便确认更新是否生效（[b249ec0](https://github.com/hjd-hitsz/codex-web/commit/b249ec0684457594910b0499acb4efad57f8f518)）。
- 关闭网页后任务继续运行，完成后及时解除对话占用，方便切换到其他 Codex 客户端（[b249ec0](https://github.com/hjd-hitsz/codex-web/commit/b249ec0684457594910b0499acb4efad57f8f518)）。
