# Codex Web

在浏览器中使用本机 Codex，支持聊天、文件编辑、Git 差异、代码审查和交互式终端。服务运行在安装 Codex 的 Linux 电脑上，电脑、手机和平板可通过 `http://电脑IP:8766` 访问。

网页沿用服务所在电脑的 Codex 登录，任务以该用户的完全访问权限执行。默认通过 HTTP 提供访问，适合在可信网络中使用。

## 环境要求

- Linux、Node.js 24 或以上、npm。
- Git：用于工作区差异和文件修改的撤销校验。
- 已安装并登录的 Codex CLI，支持 `codex app-server`；本项目已在 Codex CLI `0.162.1` 上验证。
- `/usr/bin/zsh`：网页交互式终端使用的 shell。
- 后台运行和开机启动需要 systemd 用户服务。

## 安装与启动

在安装 Codex 的电脑上，以运行 Codex 的普通用户执行：

```bash
npm install -g https://github.com/hjd-hitsz/codex-web/releases/download/v2.1.2/codex-web-2.1.2.tgz
codex-web service install
codex-web service status
```

安装包来自 [GitHub Release v2.1.2](https://github.com/hjd-hitsz/codex-web/releases/tag/v2.1.2)，已包含可直接运行的网页。npm 全局命令所在目录需在 `PATH` 中。服务安装会创建并启动网页服务和缺失的 Codex 后端服务，保留已有后端配置。

需要开机自动启动、退出登录后继续运行时，执行：

```bash
loginctl enable-linger "$USER"
```

该命令可能需要管理员授权。

启动后打开：

- 本机：`http://127.0.0.1:8766`。
- 同一网络的其他设备：`http://电脑IP:8766`，将“电脑IP”替换为服务所在电脑的实际 IP，并允许防火墙访问 `8766` 端口。

也可以下载 Release 的 `codex-web-2.1.2.tgz` 附件后执行 `npm install -g ./codex-web-2.1.2.tgz`。下载校验与更多部署选项见[部署与维护](docs/deployment.md)。

### 前台运行

如需在终端中运行，在两个终端分别执行以下命令，并保持终端打开：

```bash
# 终端一：启动 Codex 后端
codex-web backend
```

```bash
# 终端二：启动网页服务
codex-web
```

已有后端监听配置中的地址时，直接执行 `codex-web` 即可。

## 开始使用

1. 打开网页，在侧栏添加项目文件夹或选择已有项目，然后新建对话。文件夹来自服务所在电脑。
2. 也可以从“未分类”新建对话，首次发送时会自动分配独立工作目录；在输入框下方选择文件夹可指定任务目录。
3. 按需选择模型、思考强度、速度和计划模式，输入任务后按 **Ctrl+Enter** 发送，**Enter** 换行。
4. 任务运行时可继续发送补充要求；出现问题卡片时，在卡片中选择或填写回答并提交。
5. 展开“正在处理”或“工作过程”查看进度和工具记录，使用文件、差异与终端面板检查任务结果。

### 常用操作

- 对话管理：搜索、置顶、重命名、归档、恢复、删除和创建分支。对话行右侧可直接归档，归档列表可直接恢复。
- 文件与技能：输入 `@` 引用文件、目录或技能，输入 `/` 打开快捷命令；技能也可从侧栏进入。
- 思考强度：点击输入框中的思考强度入口，用滑块或方向键调整当前模型支持的档位。
- 速度：点击闪电图标切换标准与 Fast，绿色实心表示 Fast，灰色描边表示标准。切换应用于下一轮任务，Fast 会增加用量。
- 回复批注：选中助手回复文字，点击选区旁的“注释选中文字”，填写后发送；**Ctrl+Enter** 提交，**Enter** 换行。
- 内容查看：回复支持 Markdown、代码高亮、数学公式和 Mermaid 图表；图片点击放大，支持切换原始尺寸，按 **Esc** 关闭。
- 文件预览：右侧打开 Markdown 后默认显示排版结果，可通过顶部按钮切换源码编辑与预览，切换时保留未保存内容；代码、配置和脚本文件显示基础语法高亮。文件编辑后点击保存或按 **Ctrl+S**，macOS 使用 **⌘S**。
- 文件变更汇总：每轮任务结束后，回复下方的“已编辑文件”以紧凑列表显示文件名和增删行数，默认展示前 5 项，其余可展开，点击标题可收起列表。点击文件名，在右侧查看本轮差异片段，两列行号分别对应原文件和修改后的文件，区块坐标提示隐藏；点击行尾的右上箭头，打开完整文件并定位到变更，保留全文上下文，绿色标出新增行，红色显示已删除内容；点击箭头旁的源文件按钮，正常打开当前文件，显示无变更标记的正文。完整文件可继续编辑，保存时使用当前正文，Markdown 的变更以源码展示。侧栏顶部提供差异片段、全文变更和源文件的入口，查看期间保留未保存的修改；当前内容与本轮记录冲突时显示提示，可查看原差异片段。行尾撤销图标可恢复文件在该轮中的修改，遇到内容冲突时保留当前文件并显示提示。回复的复制和分支按钮位于文件汇总下方。
- 网页终端：使用 `exit` 或 **Ctrl+D** 结束 shell 后，终端自动折叠；隐藏面板时进程继续运行。

对话会自动生成简短标题，也可手动重命名。自动标题使用本机 Codex 登录与对话模型，会产生少量额外模型用量。未发送内容自动保存为草稿，发送失败后可继续重试。

桌面自动化、桌面内置浏览器和完整插件安装管理等功能由 Codex 桌面客户端提供。

## 配置

执行以下命令可创建用户配置并显示其位置，已有配置会保留：

```bash
codex-web config init
```

默认配置文件为 `~/.config/codex-web/.env`，升级后保留。可通过 `CODEX_WEB_CONFIG_DIR` 指定配置目录；使用 `XDG_CONFIG_HOME` 时，配置位于其下的 `codex-web` 目录。

常用配置项：

- `HOST`：监听地址，初始为 `0.0.0.0`，允许通过电脑 IP 访问；仅本机访问可改为 `127.0.0.1`。
- `PORT`：网页端口，初始为 `8766`。
- `CODEX_APP_SERVER_URL`：Codex 后端地址，初始为 `ws://127.0.0.1:8765`。
- `DEFAULT_CWD`：首次使用时的默认工作目录，未设置时使用当前用户的主目录。

修改配置前先结束当前任务和网页终端，保存后执行 `codex-web service restart`；前台运行时重新启动网页进程。端口变更后使用新端口访问。完整配置和后端设置见[部署与维护](docs/deployment.md#配置)。

## 升级与服务管理

升级时，从目标版本的 Release 获取安装地址。当前版本的安装与服务更新命令为：

```bash
npm install -g https://github.com/hjd-hitsz/codex-web/releases/download/v2.1.2/codex-web-2.1.2.tgz
codex-web service install
codex-web service restart-when-idle
```

最后一个命令会等待当前任务和网页终端结束后再重启，等待期间保持命令运行。升级后刷新网页，在“设置 → 关于”查看网页与服务版本；命令行可执行 `codex-web --version`。

常用服务命令：

```bash
codex-web service status             # 查看网页与后端状态
codex-web service stop               # 停止网页服务
codex-web service start              # 启动网页服务及其后端
codex-web service restart-when-idle   # 等待任务与终端结束后重启网页
codex-web --help                     # 查看全部命令
```

停止网页服务时，Codex 后端继续运行。详细升级、回退与日志查看方法见[部署与维护](docs/deployment.md)。

## 数据与常见问题

聊天记录和登录凭据由服务所在电脑的 Codex 管理；草稿、置顶、项目快捷列表、主题和摘要译文保存在当前浏览器中。“未分类”对话生成的文件保存在 Codex 配置目录下的 `codex-web/workspaces`，迁移电脑时应一并保留。

思考摘要使用 TranSmart 翻译为中文，待译摘要会发送至 `transmart.qq.com`，代码、路径和链接会先替换为占位符。翻译失败时显示原文，并可点击重试。

- 网页无法打开：运行 `codex-web service status`，检查服务状态、访问 IP、端口和防火墙。
- 网页提示后端未连接：检查 Codex 登录和后端服务状态。可用 `curl http://127.0.0.1:8766/healthz` 检查连接，HTTP 200 表示已就绪，503 表示后端未连接；自定义端口时相应替换。
- 对话显示被占用：先在持有该对话的客户端结束任务并释放对话，再点击网页的“重试”。历史记录可继续查看，恢复后草稿与附件会保留，由你继续发送。已有后端的回收设置见[对话占用与后端回收](docs/deployment.md#对话占用与后端回收)。

版本变化见[变更日志](CHANGELOG.md)，各版本安装与升级说明见 [GitHub Releases](https://github.com/hjd-hitsz/codex-web/releases)。
